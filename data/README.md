# data/ — 加密後的行程檔放這裡

## 這個資料夾是做什麼的

手機用網址開啟這個手冊時，會要求輸入「帳號」和「密碼」。
帳號決定要讀哪一個檔案：

| 帳號     | 讀取的檔案         |
|----------|--------------------|
| `tokyo`  | `data/tokyo.json`  |
| `osaka`  | `data/osaka.json`  |
| `kyoto`  | `data/kyoto.json`  |

所以要新增一趟旅程，**不需要改任何程式碼**，只要多放一個檔案進來。

## 怎麼產生這些檔案

1. 在電腦上用瀏覽器直接打開專案裡的 `index.html`（本機開啟不會要求登入）。
2. 把行程編輯／貼上到滿意為止。
3. 點畫面上方的 **「🔒 匯出加密行程檔」**。
4. 依序輸入要用的「帳號」和「密碼」，瀏覽器會下載一個 `<帳號>.json`。
5. 把下載到的檔案放進這個 `data/` 資料夾。
6. 用 GitHub Desktop commit 並 push。
7. 手機上重新整理網頁，用剛剛設定的帳號密碼登入。

## 安全性說明（重要）

這些檔案是用 AES-GCM 加密過的，金鑰由你的密碼經 PBKDF2 推導出來。
程式裡**沒有存密碼、也沒有存密碼的雜湊值**——能不能解密成功本身就是驗證。
所以就算這個 repo 是公開的，別人抓到檔案也只會看到一團亂碼。

但請記得：**保護強度完全等於密碼強度。**

- `2026` 這種四位數密碼，電腦幾乎瞬間就能試完，只擋得住不小心點進來的路人。
- 真正要放上真實班機、日期、住宿資訊之前，建議改成長一點的密碼
  （例如 `tokyo2026felix`），重新匯出一次檔案覆蓋即可。

## 不要放進這裡的東西

- 沒有加密的原始 JSON（那等於直接公開）
- 護照、證件照片、訂位代碼截圖等個人證件資料
